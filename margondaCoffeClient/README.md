tujuan utama dari website ini memudahkan manajemen chaiser, dan personal branding.


## fitur 
* login menu
* transaksi 
* history transaksi


## Project Setup
1. cloning project 
  git clone "url_clone"

2. install dependensi
cd "nama project yang di clone"
 npm install


3. menjalankan project
npm run dev


4. compile dan minify 
npm run build 


5. unit testing

npm run test:unit

6. linters
npm run lint
