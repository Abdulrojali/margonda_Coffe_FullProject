## backend margonda coffe 
rest api yang menghubungkan database dengan tampilan website dashboard chaiser pos 

## masalah yang di selesaikan 
dari pembuatan restapi masalah integrasi database dengan tampilan ui terselesaikan dan masalah utama dari usaha umkm ini terselesaikan mengenai manajemen transaksi dan stock dan juga history. 

## teknologi yang di gunakan 
bahasa pemgrogaman : javascript(Express js )
database : mysql, mongodb 
tools : vscode

## prequisite 
* node v22.9.0
* npm 11.12.1
* mongoose 2.9.2

## env.example 
karena env adalah data sensitif, maka env.example digunakan sebagai contoh anda dapat menggunakan env.example untuk project yang sudah anda clone 
* buat file .env 
* salin seluruh isi url dari file env.example 
* ganti isi url nya sesuai kebutuhan
